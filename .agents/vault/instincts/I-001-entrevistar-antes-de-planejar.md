# Entrevistar user antes de qualquer plano

**Pattern:** Sempre que o Architect inicia o planejamento de uma feature, a primeira ação é conduzir uma entrevista estruturada com o usuário antes de escrever qualquer linha do plano.

**Learning:** Planos criados sem entrevista prévia quase sempre precisam de revisão significativa depois. O custo de 5-10 perguntas antes é menor que o custo de retrabalho após um plano errado. Perguntas essenciais: escopo exato, stack preferido, edge cases conhecidos, restrições de tempo, integrações necessárias.
