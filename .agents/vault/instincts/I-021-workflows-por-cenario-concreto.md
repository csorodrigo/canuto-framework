# Workflows por cenário são mais úteis que fluxo genérico

**Pattern:** Quando o usuário pergunta "qual fluxo devo usar para X".

**Learning:** Criar workflows nomeados por situação concreta (ex: "Preciso melhorar segurança", "Preciso resolver problema complexo") em vez de um único "fluxo recomendado". O usuário decide pelo nome do cenário, não por abstração técnica. Cada workflow deve listar as skills em ordem com o propósito de cada passo.
