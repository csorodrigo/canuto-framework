# Tutorial como referência completa no chat

**Pattern:** Quando o usuário pede uma lista de skills, comandos ou funcionalidades do framework.

**Learning:** Sempre gerar tabelas completas com coluna "O que esperar" (output concreto). Nunca truncar com "+N mais". O objetivo é que o usuário consiga consultar sem sair do chat — a tabela é a referência, não um resumo.
